# Claire — Academic Homepage

Personal academic homepage for [@WonderfulClaire](https://github.com/WonderfulClaire), focused on LLM post-training, reinforcement learning, agents, multimodal learning, and speech/audio research.

[Live website](https://wonderfulclaire.github.io/academic-homepage/)

## Contents

- Current research interests and a concise introduction
- Six selected public projects with concrete starting points
- Repository experiment reports, clearly distinguished from peer-reviewed publications
- Existing public contact information

## Preview and maintenance

Open `index.html` in a browser, or serve this directory with `python -m http.server 8769`.
The site uses plain HTML, CSS, and JavaScript with no build step or third-party scripts.

Keep project links, experiment descriptions, and the GitHub profile README consistent. Add publications only with verified bibliographic information and a public source. Do not link private project repositories as public portfolio entries.

## Deployment

The site is hosted on GitHub Pages. Check the repository's Settings → Pages for the configured publishing source and Actions for deployment results. This repository does not contain a custom `deploy.yml` workflow; a commit alone is not confirmation that the live site has updated.
